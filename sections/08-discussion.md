# Second poll 📱

<div class="grid grid-cols-2 gap-6 mt-5">

<div>

<div class="text-2xl font-bold">menti.com</div>
<div class="text-3xl font-bold tracking-widest text-fuchsia-600 mb-4">0000 0000</div>

<div class="text-xs tracking-widest text-indigo-500 mb-2">FOUR QUESTIONS</div>

<div class="text-sm space-y-1.5">

1. **Did you get it running?** yes · nearly · no · already had it
2. **Where did it help most?** *(multiple choice)*
3. **Did it get anything wrong?** *(open text — collect these)*
4. **Would you trust it on analysis code that reaches a paper?** *(1–5)*

</div>

</div>

<div class="rounded-lg bg-amber-50 border-l-4 border-amber-500 p-5">

<div class="text-xs tracking-widest text-amber-700 mb-2">Q3 IS THE ONE THAT MATTERS</div>

<div class="text-sm space-y-2">

Every wrong answer someone found today is worth more to the room than anything on the previous
forty slides — it is **specific, local, and undeniable**.

Read three of them out. Ask the author what tipped them off.

Q4 usually splits the room. **That split is the discussion; do not resolve it.**

</div>

<div class="text-xs tracking-widest text-indigo-500 mb-2">IF THE DISCUSSION STALLS</div>

# Twelve prompts

<div class="grid grid-cols-2 gap-6 mt-4 text-sm">

<div>

<div class="text-xs tracking-widest text-emerald-600 mb-1.5">ON PRACTICE</div>

<div class="space-y-1">

1. Who has changed how they write code because of this, and how?
2. What is the last thing it got confidently wrong for you?
3. Does anyone review AI-written code differently from human-written code? Should we?
4. Has anyone stopped using it for something specific? Why?

</div>

<div class="text-xs tracking-widest text-blue-600 mt-3 mb-1.5">ON RESEARCH INTEGRITY</div>

<div class="space-y-1">

5. Should the methods section say the analysis was AI-assisted?
6. If a reviewer asked "was this AI-generated?", what would you honestly answer?
7. Whose name is on a bug that reached print?

</div>

</div>

<div>

<div class="text-xs tracking-widest text-fuchsia-600 mb-1.5">ON THE GROUP</div>

<div class="space-y-1">

8. What belongs in a **shared** `copilot-instructions.md` for this department?
9. What data must never be open in an editor with this enabled — can we write that list today?
10. Who is going to teach the next person, and how do they find out it exists?

</div>

<div class="text-xs tracking-widest text-rose-600 mt-3 mb-1.5">ON THE UNCOMFORTABLE BIT</div>

<div class="space-y-1">

11. What happens to how a PhD student **learns to code** when this is available from day one?
12. Are we faster, or does it only *feel* faster? What would we need to measure to know?

</div>

</div>

</div>

<div class="mt-3 text-xs opacity-60 border-l-4 border-amber-400 pl-3 py-1 bg-amber-50/50">
Prompt 12 has a real literature behind it — METR's 2025 developer study found experienced developers were <em>slower</em> with AI assistance while believing they were faster.
</div>
