# Examples — Coding Café, 8 September 2026

Every prompt in the deck has a real file behind it. Nothing here is a screenshot: the scripts run,
the data is generated deterministically, and the numbers quoted on the slides are the numbers these
files actually produce.

**All data is synthetic.** No patient data, no real participants, nothing identifiable.

## Run anything from this folder

```bash
cd examples
```

Paths inside the scripts are relative to `examples/`, so run them from here:

```bash
Rscript R/ex03_clean_data.R
```

**Requirements.** R with `readr`, `dplyr`, `ggplot2` (installed on the demo machine), and Python 3
with `pandas`. Two examples mention packages that are *not* installed on purpose — `here` and
`testthat` — because installing them is part of the exercise.

## The data

Generated by [`tools/make_data.py`](tools/make_data.py) with a fixed seed. Regenerate with:

```bash
python3 tools/make_data.py
```

| File | Rows | What it is for |
|---|---|---|
| `data/participants.csv` | 1,186 | 1,180 with an ID + **6 with a blank ID**. `sex` is coded **1/2** |
| `data/visits.csv` | 2,601 | One row per visit. **1,204 baseline rows for 1,180 participants** |
| `data/lab_export.csv` | 600 | Spans 2024 **and** 2025, so "keep only 2025" does something |
| `data/example.csv` | 201 | Intermediate lane. 200 participants, **one duplicated id**, some missing |
| `data/schema.csv` | — | The data dictionary the `copilot-instructions.md` tells Copilot to respect |

**The numbers are load-bearing.** Example 3's slide says the merge produces 1,204 rows where 1,180
were expected; `Rscript R/ex03_clean_data.R` prints exactly that. If you regenerate the data with a
different seed, re-check the slide.

## Bugs that are there on purpose

Each of these is the actual teaching point of its example. None is an accident — if you tidy them
away, the example stops working.

| Where | The bug | Why it matters |
|---|---|---|
| `ex02_inherited_analysis.R` | `n` looks like a participant count; it is a **visit** count | Runs fine, has been in two grant reports. The quiet kind |
| `ex03_clean_data.R` | 24 participants have two baseline rows | The fix is a research decision, not a code fix |
| `ex05_write_tests_for_me.py` | `.agg("mean")` silently averages those duplicates | A generated test will certify it and pass |
| `ex06_merge.R` | Lab IDs read as numbers, participant IDs as text | Fails loudly. That is the *good* kind |
| `ex07_recode/` | Four recodes, **three different answers** for a missing sex | Run `show_the_difference.R` before demoing |
| `ex09_standardise_pid.R` | `formatC(flag="0")` pads with **spaces**, not zeros | `/doc` will confidently document the intent, not the behaviour |
| `r3_monolith.R` | `setwd()`, absolute paths, silent inner joins, no lockfile | Four prompts, ninety seconds each |
